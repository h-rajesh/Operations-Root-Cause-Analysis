# Operational Root Cause Analysis & Bottleneck Reduction

**Category:** Operations problem-solving  
**Data:** Synthetic / simulated only  
**Methods:** 4M analysis, 5 Whys, corrective-action tracking

## Files
- `before_after_operations.csv` — illustrative baseline and follow-up data
- `before_after_comparison.xlsx` — spreadsheet copy of the comparison data
- `root_cause_analysis.md` — problem framing and measurement plan
- `4m_analysis.md` — people, machine, method and material hypotheses
- `5_whys_analysis.md` — example cause chain with validation caveat
- `corrective_action_tracker.csv` — proposed actions and owners

## How to use
Start with the problem statement, list possible causes, identify evidence needed, validate the cause, implement an action, then compare relevant metrics.

## Important
The before/after data is invented for portfolio demonstration. It does not prove that the proposed actions caused an improvement and is not based on Amazon operations.
